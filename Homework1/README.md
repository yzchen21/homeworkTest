# Homework 1 —— C 语言基础：输出、数据类型与格式化

## 一、作业说明

本次作业共 4 个任务（Task 1 ~ Task 4），只使用标准库 `stdio.h`。每个任务是一个独立的 `.c` 文件、各自包含一个 `main` 函数，可分别单独编译运行。

| 项目 | 要求 |
| --- | --- |
| 提交位置 | `Homework1/<学号>/`（例如 `Homework1/2604020312/`） |
| 文件命名 | `task1_card.c`、`task2_types.c`、`task3_table.c`、`task4_bonus.c` |
| 源文件编码 | **UTF-8**（不要用 GBK 保存，否则中文输出乱码） |
| 文件头注释 | 每个文件开头写明：学号、姓名、班级、题目、说明 |
| 开发环境 | Visual Studio / MSVC x64，或任意支持 C99 的编译器 |

> 注意：本目录下的 `README.md` 是作业题目说明，请勿删除或改名。学生只需在 `Homework1/<学号>/` 下提交自己的源码。

## 二、任务清单

### Task 1 个人信息卡片（`task1_card.c`）

**题目：** 使用 `printf` 输出一个带边框的文本"个人信息卡片"。

**要求：**

1. 卡片用 `+`、`-`、`|` 组成边框，横线长度与内容宽度一致，保证右边界整齐对齐。
2. 卡片内至少包含：姓名、学号、班级、专业、座右铭，每项一行。
3. 一个汉字在终端占 2 列宽，补空格时按显示宽度计算，不要按字节数。
4. 所有输出都用 `printf` 完成，每行字符串末尾显式写 `\n`，最后 `return 0;`。

**输出示例：**

```text
+--------------------------------+
|          个人信息卡片          |
+--------------------------------+
| 姓名：余梓宸                   |
| 学号：2604020312               |
| 班级：26电子信息工程3班        |
| 专业：电子信息工程             |
| 座右铭：海阔凭鱼跃，天高任鸟飞 |
+--------------------------------+
```

### Task 2 基本数据类型（`task2_types.c`）

**题目：** 分别定义 `int`、`float`、`double`、`char` 四种类型的变量并输出，观察不同类型在内存中的精度差别。

**要求：**

1. 定义四个变量：`int age`、`float height`、`double pi`、`char blood`，并赋初值。
2. 用 `printf` 按"类型 变量名 = 值"的格式逐行打印，使用对应格式说明符：`%d`、`%f`、`%f`、`%c`。
3. `height` 用 `%.6f` 输出；`pi` 用 `%.15f` 输出，并把 `3.14159265358979323846` 分别存成 `float` 与 `double` 各打印一次，用可见的数字差异说明 `float` 只有约 7 位有效数字、会发生精度丢失。
4. `float` 变量赋初值时必须加后缀 `f`（如 `1.72f`），避免 `double` 到 `float` 的隐式转换警告。

**输出示例：**

```text
int     age     = 19
float   height  = 1.720000
double  pi      = 3.141592653589793
char    blood   = A

pi 作为 float  : 3.141592741012573
pi 作为 double : 3.141592653589793
```

### Task 3 格式化表格（`task3_table.c`）

**题目：** 用 `printf` 的宽度控制输出一张对齐的商品价目表。

**要求：**

1. 表格至少 3 列：编号、名称、单价，并有一行表头。
2. 使用宽度修饰符控制对齐：右对齐用 `%6d`、`%10.2f`，左对齐用 `%-12s`。
3. 单价保留 2 位小数。
4. 至少输出 4 行数据（铅笔、笔记本、橡皮、圆规）。

**输出示例：**

```text
  编号 名称               单价
     1 铅笔               1.50
     2 笔记本             5.80
     3 橡皮               0.75
     4 圆规              12.00
```

---

### Task 4 英寸转厘米（`task4_bonus.c`）

**题目（附加题）：** 已知 `1 inch = 2.54 cm`，输出 1 ~ 5 英寸对应的厘米值。

**要求：**

1. 用 `for` 循环输出 1、2、3、4、5 英寸的换算结果，格式为 `N inch = X cm`。
2. 结果用 `%5.2f` 保留 2 位小数，小数点对齐。
3. 数值必须通过 `英寸数 * 2.54` 计算得出，不允许直接写死结果。

**输出示例：**

```text
1 inch =  2.54 cm
2 inch =  5.08 cm
3 inch =  7.62 cm
4 inch = 10.16 cm
5 inch = 12.70 cm
```

## 三、编译与运行

每个文件都是独立程序，可单独编译：

```bash
cl task1_card.c        # MSVC 命令行，需先运行 vcvars64.bat
task1_card.exe
```

或在 Visual Studio 中把文件加入工程后按 `F5` 运行。
